# Restore original UI

These files are exact copies of `index.html`, `ai.html`, `notes.html`, and `4096.html` from before the liquid-glass restyle (17 Sep 2026).

To restore a page, copy it back over the live file:

```
cp _backup/index.html index.html
cp _backup/ai.html ai.html
cp _backup/notes.html notes.html
cp _backup/4096.html 4096.html
```

A git branch `backup/ui-before-liquid-glass` was also created with the previous tree.
