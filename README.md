Free, fast, and modern AI assistant with image support, streaming responses, and a clean, user-friendly interface.

## ✨ Features

- 🤖 AI-powered chat
- 🖼️ Image support
- ⚡ Streaming AI responses
- 🎨 Modern and responsive interface
- 🌙 Multiple themes
- 📱 Mobile-friendly design
- 🧩 Dynamic interface and interactive components
- 💻 JavaScript-focused development features
- 📚 JS Tutor for learning JavaScript
- 🔄 Regular updates and interface improvements
- 🆓 Free to use
- 🚫 No advertisements
- 🔐 No registration required

## 🛠️ Technology Stack

Ermak X is a browser-based AI application built with modern web technologies.

### Core technologies

**HTML5** — application structure and interface

**CSS3** — responsive design, themes, animations, and visual components

**JavaScript (ES6+)** — core application logic, AI communication, streaming responses, user interactions, image handling, and dynamic interface updates

**Web APIs** — browser-side functionality and asynchronous communication with AI services

JavaScript is a core part of Ermak X. The application relies on JavaScript for its main functionality rather than using it only for minor interface interactions.

## 📚 JavaScript Focus

JavaScript is one of the central technologies of Ermak X.

The application includes a dedicated **JS Tutor** designed specifically for learning and practicing JavaScript.

JS Tutor provides:

- JavaScript lessons
- Structured explanations
- Progressive learning topics
- JavaScript questions and quizzes
- Code-based questions
- Multiple-choice exercises
- Automatic answer checking
- Explanations of correct answers
- Lesson completion tracking
- The ability to repeat completed lessons
- Local storage of completed lessons on the user's device

The JavaScript Tutor is integrated directly into the Ermak X web application and uses the same AI infrastructure as the main application.

## 🎓 JS Tutor

JS Tutor is a dedicated JavaScript learning mode inside Ermak X.

A typical learning session works like this:

1. Start a JavaScript lesson.
2. The AI generates a lesson based on the user's learning history.
3. Read the explanation.
4. Answer 10 questions.
5. Receive immediate feedback.
6. See explanations for answers.
7. Get a final result.
8. Save the completed lesson.
9. Repeat the lesson later or generate a new one.

Previously completed lessons are provided to the AI so that new lessons can avoid unnecessarily repeating the same topics.

Completed lessons are stored locally on the user's device.
